# Археологическая карта Беларуси — прототип

Закрытый веб-инструмент для археологов: карта памятников, фильтры по типу, времени, культуре и находкам, карточка памятника со ссылкой на страницу издания и готовой ссылкой по ГОСТ, правка координат.

> **Публичная демо-версия на GitHub Pages — временная заглушка.** Сканов книг здесь нет, описания сокращены до коротких цитат. Полная версия со сканами — только для участников проекта.

## Что внутри

| Путь | Что это |
|---|---|
| `index.html`, `css/`, `js/` | Фронтенд без сборки (ES-модули). Работает на любом статическом хостинге |
| `data/sites.json` | 2 959 памятников из каталога Поболя (1983), координаты для 2 001 |
| `data/corpus.json` | Издания и индекс страниц |
| `data/basemap.json` | Встроенная схема: граница, области, реки (Natural Earth) — запасная подложка |
| `vendor/` | Leaflet 1.9.4 и Leaflet.markercluster 1.5.3 (BSD-2 / MIT) |
| `tools/sources/` | Сбор литературы: репозитории вузов (DSpace), history.by, ИА РАН; скачивание с метаданными; разбор каталога Поболя |
| `tools/pipeline/` | Сборка данных сайта: геокодинг (GeoNames → OpenStreetMap), упоминания, пачки страниц |

## Откуда данные и насколько им верить

- **Памятники** — автоматический разбор каталога: Поболь Л. Д. *Археологические памятники Белоруссии: Железный век.* Минск, 1983. Найдено ≈94% номеров каталога.
- **Координаты** — центр населённого пункта (GeoNames, OpenStreetMap). У всех точек точность «до нас. пункта», ±1,5 км. Памятники одной деревни на карте слегка разнесены, в карточке — исходные координаты.
- **Тип, культура, датировка, находки** — по ключевым словам в описании, требуют проверки. Датировка «по культурам» — границы культуры, а не памятника.
- **Упоминания в других книгах** пока не подключены: автоматический поиск даёт много ложных совпадений. Следующий шаг — проверка кандидатов через Jev/LLM.

## Запуск локально

```bash
python -m http.server 8000
# открыть http://localhost:8000
```

Открывать `index.html` двойным кликом нельзя: браузер не даст загрузить JSON с диска.

## Где хранятся правки

- В демо (Pages, локально) правки координат, сохранённые наборы и сообщения об ошибках OCR лежат в `localStorage` браузера.
- В закрытой версии — в общей базе, с историей правок и ролями.

## Подложки карты

«Карта» — OpenStreetMap, «Спутник» — Esri World Imagery, «Схема» — встроенная (работает без интернета). Google Maps как подложку можно подключить через официальный Maps JavaScript API (нужен ключ с биллингом). Из карточки памятника есть ссылки «Открыть в Google Картах / Яндекс» на ту же точку.
